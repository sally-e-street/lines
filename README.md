# README 

**data** folder contains the following files:

signBase_Version1.0_selection.csv - this file contains data for n=531 artefacts from SignBase version 1 (Dutkiewicz et al. 2020, downloaded from here: https://www.signbase.org/download/). Columns 1-55 contain original data from SignBase. Columns 56-57 have been manually added by the author. Column 56 ('include') indicates whether the artefact was included (1) or excluded (0) from the final dataset, and column 57 ('notes') briefly describes the reason for the inclusion or exclusion.

WoS_butchery_search_selection.csv - this file contains data for n=351 articles obtained from a Web of Science search for articles containing images of butchered faunal remains from Palaeolithic contexts. Columns 1-71 contain original data exported from the Web of Science search. Columns 72-73 have been manually added by the author. Column 72 ('include') indicates whether the article contained any usable images (1) or not (0), and column 73 ('notes') briefly describes the reason for the inclusion or exclusion of the article.

additional_butchery_articles.csv - this file contains data from n=84 articles consulted to obtain additional images of butchery markings following the Web of Science search. Columns are as follows: 'author' = surname of the first author of the article, 'year' = year of publication, 'URL' = weblink to article, 'images selected' = article figures selected for inclusion in the dataset, 'cited in' = author and year of the review article in which the primary article is cited ('NA' for articles which are themselves review articles), 'notes' = brief descriptions of the reasons for the inclusion or exclusion of articles/images.

WoS_geology_search_selection.csv - this file contains data for n=26 articles obtained from a Web of Science search for articles containing images of 'elephant skin' rock weathering. Columns are as follows: 'author' = surname of the first author of the article, 'year' = year of publication, 'URL' = weblink to article, 'include' indicates whether the article contained any usable images (1) or not (0), notes' = brief descriptions of the reasons for the inclusion or exclusion of articles. 

image_metadata.csv - this file contains metadata for the n=162 images selected for inclusion in the analyses. Columns are as follows: 'sample' = which sample the image belongs to, one of 'Butchery' = butchery markings, or 'incidental' markings, 'Intentional' = intentional markings, 'Geology' = geological markings (elephant skin weathering) or 'Query' (putative intentional engravings, some with controversial attributions).
