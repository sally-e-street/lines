# README 

data folder contains the following files:

signBase_Version1.0_selection.csv - this file contains data for n=531 artefacts from SignBase version 1 (Dutkiewicz et al. 2020, downloaded from here: https://www.signbase.org/download/). Columns 1-55 contain original data from SignBase. Columns 56-57 have been manually added by the author. Column 56 ('include') indicates whether the artefact was included (1) or excluded (0) from the final dataset, and column 57 ('notes') briefly describes the reason for the inclusion or exclusion.

WoS_butchery_search_selection.csv - this file contains data for n=351 articles obtained from a Web of Science search for articles containing images of butchered faunal remains from Palaeolithic contexts. Columns 1-71 contain original data exported from the Web of Science search. Columns 72-73 have been manually added by the author. Column 72 ('include') indicates whether the article contained any usable images (1) or not (0), and column 73 ('notes') briefly describes the reason for the inclusion or exclusion of the article.
