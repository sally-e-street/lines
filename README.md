# README 

**data** folder contains the following files:

signBase_Version1.0_selection.csv - this file contains data for n=531 artefacts from SignBase version 1 (Dutkiewicz et al. 2020, downloaded from here: https://www.signbase.org/download/). Columns 1-55 contain original data from SignBase. Columns 56-57 have been manually added by the author. Column 56 ('include') indicates whether the artefact was included (1) or excluded (0) from the final dataset, and column 57 ('notes') briefly describes the reason for the inclusion or exclusion.

WoS_butchery_search_selection.csv - this file contains data for n=351 articles obtained from a Web of Science search for articles containing images of butchered faunal remains from Palaeolithic contexts. Columns 1-71 contain original data exported from the Web of Science search. Columns 72-73 have been manually added by the author. Column 72 ('include') indicates whether the article contained any usable images (1) or not (0), and column 73 ('notes') briefly describes the reason for the inclusion or exclusion of the article.

additional_butchery_articles.csv - this file contains data from n=84 articles consulted to obtain additional images of butchery markings following the Web of Science search. Columns are as follows: 'author' = surname of the first author of the article, 'year' = year of publication, 'URL' = weblink to article, 'images selected' = article figures selected for inclusion in the dataset, 'cited in' = author and year of the review article in which the primary article is cited ('NA' for articles which are themselves review articles), 'notes' = brief descriptions of the reasons for the inclusion or exclusion of articles/images.

WoS_geology_search_selection.csv - this file contains data for n=26 articles obtained from a Web of Science search for articles containing images of 'elephant skin' rock weathering. Columns are as follows: 'author' = surname of the first author of the article, 'year' = year of publication, 'URL' = weblink to article, 'include' indicates whether the article contained any usable images (1) or not (0), notes' = brief descriptions of the reasons for the inclusion or exclusion of articles. 

image_metadata.csv - this file contains metadata for the n=162 images selected for inclusion in the analyses. Columns are as follows: 'sample' = which sample the image belongs to, one of 'Butchery' = butchery markings, or 'incidental' markings, 'Intentional' = intentional markings, 'Geology' = geological markings (elephant skin weathering) or 'Query' (putative intentional engravings, some with controversial attributions). 'image_ID' = unique code used to identify image and match it to its corresponding line coordinates. For the butchery and query samples, Image_ID code follows the format 'sample_authoryear_figure', e.g. 'B_Blasco11_Fig3a' = image of butchery markings from Blasco 2011, Figure 3a. For the geological sample, Image_ID code follows the format 'sample_authoryear_row_column', where row and column number refer to the grid applied to split the image into multiple windows. For the intentional sample, Image_ID code comprises the sample 'I_' followed by the unique code for each artefact used in the SignBase dataset. 'author' = surname of the first author of the article/source for the image. 'year' = year of publication for the article/image. 'URL' = weblink to article/image, where available. 'site' = archaeological site where markings identified, 'age' = age of markings/archaeological site (where available/applicable - age estimates are not provided for geological markings). Please note that age estimations are taken directly from original articles and vary widely in their methodology and precision. 'photo' = whether or not a photographic image of the markings is accessible from the original source ('Yes') or only a drawing/tracing ('No'). 'how found' = how the article was located, either 'SB database' (from the SignBase database), 'WoS search' (from a systematic Web of Science search), 'general literature' = general (non-systematic) consultation of relevant literature, 'Personal communication' = direct communication with photographer. 'notes' = brief notes explaining any complexities of the image and how they were resolved (e.g. explaining which of multiple views of the artefact was selected).

**SS_coords** folder contains coordinates of n=162 line sets manually traced by the first author (SS), plus n=50 simulated line sets (n=212 total). Coordinates for each line set are stored in separate CSV files, in which each row represents a single line, with four columns: 'x1' = x coordinate of line start point, 'x2' = x coordinate of line end point, 'y1'= y coordinate of line start point, 'y2' = y coordinate of line end point.

**SS_coords2** folder contains coordinates of n=30 line sets manually re-traced by the first author (SS) to check for intra-rater reliability - formatted as above.

data_preparation.R - annotated R script demonstrating how coordinate data were prepared for analysis (not fully reproducible).
